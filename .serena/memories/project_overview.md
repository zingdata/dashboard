# Dashboard Project Overview

## Purpose
This is a Flutter package called `dashboard` that provides a dynamic dashboard widget allowing users to create their own layouts with resize, move, and auto re-layout capabilities. The package is published to pub.dev at version 0.0.3+1.

## Key Features
- **Dynamic Layouts**: Users can create and customize dashboard layouts
- **Resize**: Items can be resized by long-press (mobile) or drag (desktop/web)
- **Move**: Items can be moved/repositioned interactively
- **Auto Re-layout**: Automatic repositioning when slot count changes
- **Storage Delegate**: Persistent storage of layouts via custom delegate pattern
- **Slot-based Grid**: Responsive grid system with configurable slot count and aspect ratio
- **Edit Mode**: Interactive editing with visual feedback and background painter
- **Swapping**: Items can swap positions when dragged over each other (custom addition)
